Run the full app locally

Download or clone the repository, start Docker Desktop, and open a terminal in the folder containing compose.yaml.

HEKY_PORT=8010 docker compose up --build -d

After the containers start, open http://localhost:8010 on your own computer. Configure your Google Routes API key in your local .env file for live route estimates.

No account or booking is created on this showcase. Do not enter API keys or passwords here.
